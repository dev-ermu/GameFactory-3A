# Ref2VA

当一个或多个参考源提供可复用的内容、画面帧、动态效果、时序信息或音频时使用此模式。

- 将`mode`参数设为`reference_to_video`；仅使用适用的顶层参考路径数组。
- 根据检测结果或用户的明确说明为每个角色赋值。若某材质无法辨识出可用角色，需向用户询问；绝不可仅凭路径自行推断角色。
- 需区分可复用的可见内容、具体的画面锚点、源视频编辑或动态效果，以及复制或引用的音频。切勿让一个参考源承担无关的角色。
- 若参考源仅提供外观信息，仅需保留请求所需的相关属性，即识别出的身份、身体、面部、头发、服饰或装备；明确排除其背景、光线、姿势和构图信息。仅列出适用的属性。
- 仅当明确需要某参考视频中的同步音轨时方可使用；视频中存在声音并不等同于该视频属于音频参考源。
- 保持每个角色的稳定性，并注明该角色生效的具体镜头或时间点。
- 标签、定义、关系标记、章节顺序及参考源数量限制均需遵循所选的模型配置文件要求。
