# I2VA

仅当某张图像明确作为第一帧时使用。

- 将`mode`参数设为`first_frame_to_video`，并把该图像的路径填入`first_frame_path`。
- 将提供的图像视为开场镜头中恰好处于0.00秒时刻的状态。
- 仅保留经检验确认或用户明确声明的信息。若该图像不透明，则将其置于中性位置，无需列举未观察到的属性。
- 从已检验的图像中，仅保留与运动相关的锚点：主要主体、前景/背景布局、关键物体、光线以及空间关系。不要列出不影响所请求变化效果的细微装饰元素。
- 如果所请求的运动涉及未被确认的可见主体，在撰写内容前需先询问要动画化或跟随的主体是哪个。
- 遵循以下流程：第一帧锚点 → 动作起始 → 持续演变 → 可见结果或反应。
- 若请求进行焦点切换，除非同时要求镜头移动，否则保持相机静止；需说明哪些部分先清晰呈现、焦点如何变化，以及哪些部分最后清晰呈现。
- 对于短片段，优先采用连续拍摄方式。仅在用户明确要求，或为了展示新信息而必须切镜时才添加剪辑。
- 第一帧的标签标注、绑定指令以及提示词放置方式，需遵循所选用的模型配置要求。
- 不要添加`last_frame`或`reference-array`字段。
