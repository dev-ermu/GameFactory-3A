# 宣传模板

展示游戏类别、其独特的可玩性亮点，以及能印证该亮点的直观画面。

- 先明确游戏类型或可玩场景，随后通过角色、动词、工具、载具、机制或任务难题，尽早引出吸引玩家的核心看点。
- 每个段落只证明一个功能：先铺垫情境 → 角色采取行动 → 系统、对手或世界作出反馈 → 呈现成果。切勿用标题卡或口头宣称来代替实际演示。
- 在引入新功能前，先通过更复杂的玩法、全新的互动方式、战术变化或更重大的后果来深化已有的核心玩法亮点。
- 若涉及重复出现的协作角色，只需保留演示该功能所需的可见数量、角色定位、编队形式、移动路径、目标及任务归属信息即可。
- 若该功能的运作依赖于角色位置、入口、边界、掩体、目标、路线或任务目标，需精准呈现相关地理信息；在采取不可逆操作前先明确各元素间的关联，确保行动路径不相互冲突。
- 摄像机的视角、高度和移动方式需服务于玩家期望的体验，同时要保证角色与目标之间的方向关系清晰可见；即便采用戏剧化的拍摄角度，也不得颠倒动作逻辑或遮挡成果展示。
- 结尾需给出可玩性或游戏范围的实证：比如任务目标达成、系统状态改变、挑战难度升级，或是揭示玩家期待的内容。
- 保留提供的标题或界面文字，不得自行编造口号、徽标、用户界面、奖项或宣称性内容。为动作搭配音效；让音乐辅助营造氛围，而非取代动作音效。
