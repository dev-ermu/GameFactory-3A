# 过场动画模板

设计一个自然的过渡情节，用以改变角色在游戏中能做的事、所掌握的信息、欲望或必须面对的挑战。

- 从给定的游戏状态切入；保留角色所在位置、朝向、携带的物品、人际关系以及当前目标。仅需补充实现该变化所需缺失的信息。
- 展示触发事件或契机 → 可见的反应 → 后续结果 → 持久的新状态。要确保即时目标或结果的利害关系清晰可辨。
- 每个过场仅呈现一个动作、反应、决策或具体台词。先展示起因再呈现反应；同时保留屏幕中的方向感和空间布局。
- 对话需与可视化的行为相匹配，而非单纯的剧情概述。要保持角色身份、道具、说话者标识及相关角色定位的一致性。
- 结尾处需完成可玩状态的移交：为下一步行动准备好对应的路径、威胁、物品、人际关系或目标状态。
- 仅放慢重点动作的播放节奏；除非另有要求，否则其后续结果需以正常速度呈现。
