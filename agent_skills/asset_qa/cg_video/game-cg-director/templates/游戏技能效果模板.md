# 终极模板

展示一种标志性技能，确保使用者、作用空间、功能、威力以及预期效果在全程都能清晰可见。

- 从设定意图中选择合适的戏剧性功能：激活或角色亮相、攻击与结果、冲突，或是强力对决。若请求仅明确了技能威力，切勿凭空添加接触、伤害或二次攻击情节。
- 在效果展开前，先说明使用者、目标或受影响区域（若存在）、面对的对象、能量来源，以及预期的路径或作用范围。
- 遵循“提示/准备 → 激活/释放 → 威力的可视证明 → 预期反应、后续效果或最终姿态”的逻辑。只有当技能命中目标时，才描述其移动与接触过程。
- 让效果清晰展现能量的起始点、移动轨迹或占据的空间，以及它所带来的改变。次要粒子不得遮挡身体动作、作用边界、接触细节或反应表现。
- 视觉与音效的层级需与重要性相匹配：提示阶段先于动作呈现，激活、释放或撞击时刻达到高潮，随后逐渐减弱以凸显最终结果。
- 保持屏幕方向与角色的空间关系不变。可移动镜头来展示身体机制、技能表现或状态变化，待其他角色仍具相关性时，再恢复易读的画面布局。
- 为多名表演者分配独立的阶段与发言标识；在模型限制范围内延长持续时间，避免完整的台词与技能表演相互重叠。
