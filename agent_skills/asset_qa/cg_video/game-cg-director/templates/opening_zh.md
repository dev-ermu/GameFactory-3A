# 开场模板

介绍游戏世界、其运行逻辑以及接下来需要重点关注的内容。将开场视为可游玩的剧情呈现，而非单纯展示画面之美。

- 通过可观察到的活动来展现游戏类型与世界观。
- 根据视觉任务、空间清晰度、动作连贯性、可用时长以及模式来选择镜头和剪辑方式。
- 在内容易于理解的前提下，将空间与活动元素结合呈现；一旦新的视角能更清晰地展现空间、动作或焦点，就进行切换。
- 以地标、路线、边界、目标或移动中的物体作为空间锚点；若需保持连贯性，就要保留该锚点或其对应的核心活动。
- 结尾要体现出核心主体、行动方向、目的地或明确的冲突点，让玩家能清晰感知后续走向。

切勿自行编造标题、旁白、背景设定说明，也别加入无关的最终全景画面。
