# 声音

- 播放人声、歌声、可见物体的声响以及动作音效。将动作音效与可见物体或已确定的屏幕外声源相关联；仅靠声音无法替代场景中具有决定性作用的参与者。
- 涵盖环境音、物理动作音效以及非语言类人类发声，但不要重复已有的台词内容。
- 若需要仅面向观众的背景音乐，需为其设定一条与视觉节奏相匹配的功能性脉络——根据情况安排音乐的引入、渐强、高潮/中断以及收尾。描述乐器配置、节奏、节拍以及可听见的动态变化，切勿仅凭氛围凭空捏造音乐流派。
- 确保剧中音和非剧中音区分明确，且与视觉时间线保持一致。
- 让核心游戏事件的音效拥有最清晰的听觉峰值；将次要音层音量调低，以便能清晰辨识其声源与效果。
- 遵循选定的模型模板中关于字段名称、摆放位置以及静音/无音乐状态的标注规则。
