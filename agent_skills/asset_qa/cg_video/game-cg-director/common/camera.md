# 摄像机术语表

在镜头描述中，需将摄像机运动表述为符合场景逻辑的自然动作。仅当运动范围或节奏对叙事至关重要时，才需注明运动类型、幅度及速度。

| 类型 | 含义 |
| --- | --- |
| 推近/拉远 | 摄像机位置保持不变，仅改变焦距。 |
| 向前推进/向后拉远 | 摄像机沿前后方向移动。 |
| 向左摇摄/向右摇摄 | 摄像机从固定点水平转动。 |
| 向左平移/向右平移 | 摄像机沿水平方向移动。 |
| 向上倾斜/向下倾斜 | 摄像机从固定点垂直转动。 |
| 向上升降/向下升降 | 摄像机沿垂直方向移动。 |
| 弧形运动 | 摄像机沿弧形轨迹环绕拍摄对象运动。 |
| 跟拍 | 摄像机跟随移动中的拍摄对象。 |
| 静态拍摄 | 摄像机位置与镜头均保持不动。 |
| 轻微抖动/强烈抖动 | 使画面产生轻微或强烈的抖动效果。 |
| 第一人称视角 | 呈现拍摄对象的所见视角。 |
| 顺时针旋转/逆时针旋转 | 摄像机绕镜头轴线转动。 |

仅当具有实际意义时，才可使用“幅度较小”、“幅度较大”、“速度较慢”或“速度较快”等描述。切勿在描述末尾堆砌无解释的摄像机术语。

焦点变化不属于摄像机运动。若需描述焦点变化，需说明焦点的起始位置与最终位置、构图是否保持静止，以及最终清晰呈现的内容。除非用户明确要求，否则焦点变化过程中无需提及摄像机位移。

## 摄像机运用原则

- 为每个镜头设定明确的视觉任务：确立空间关系、展现拍摄对象、跟拍动作、呈现反应，或定格结果。摄像机运动必须服务于该任务，而非单纯为了装饰。
- 当存在两侧、边界或方向性动作易产生混淆时，需说明摄像机相对于它们的位置、镜头朝向、拍摄对象的面向或移动方向，以及拍摄目标。优先采用正向的几何描述，而非负面的警告性表述。
- 剪辑过程中需保持既定的动作轨迹与画面方位关系；仅在过渡能明显重新确立新的空间关系时，方可更改这一关系。
- 当动作涉及人体运动、道具或特定目标时，需完整呈现其运动路径。只有在二者关系明确或仍可见时，才可切换为特写镜头。
- 对于跟拍或跟踪拍摄，需说明被跟随的对象、摄像机的相对位置以及最终的构图。切勿让背景中的物体被误认为是摄像机的拍摄目标。
- 每个运动镜头的结尾需呈现所要求的画面结果，或为下一个镜头提供清晰的空间参照点。

需清晰表述动作的来源、方向、目标及结果。短镜头中尽量采用一种主导性的摄像机运动，且该运动需与拍摄对象的动作相协调；在关键接触或揭示时刻可适当减少运动幅度。切勿强行让一种摄像机运动跨越边界或同时完成多个无关的视觉任务，此时应改用剪辑处理。
