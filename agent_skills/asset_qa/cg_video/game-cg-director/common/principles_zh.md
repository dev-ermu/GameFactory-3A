# 提示词编写原则

## 可观测范围
- 仅描述可见、可听或具有时间属性的事件。通过姿态、面部表情、动作、光线、言语或声音来传达情绪。
- 所选的游戏目的需具备可观测性：开场用于构建游戏世界，过场动画用于改变可玩情境，终极技能展示特定能力及其预期效果，宣传内容用于展示功能或幻想设定。切勿将其简化为普通的电影蒙太奇。
- 按照播放顺序陈述主体、环境、动作和结果。用户提供的对话、歌词及可见文本需原样保留。
- 为每一个提供的参考项明确其职责。仅使用已核实的事实或用户的明确描述；绝不可根据路径或文件名自行推断内容。
- 若参考项的内容无法获取，则保持其模糊性。只有当某个未经证实的事实是规划指定动作或终点所必需的时，才提出询问。
- 在仅有文字描述的场景中，仅添加该场景或活动所需的通用角色、载具、物体或动作。其放置需符合场景目的、可读性、连贯性及时间要求。身份、品牌和情节信息无需明确说明；仅当动作或镜头切换的连贯性有要求时，才说明具体数量。
- 若有可用的可执行样式映射，需用其替换游戏内的简称。不可仅凭样式就自行添加剧情、天气、特效或摄像机行为。

## 分镜与表演
- 分镜设计需基于当前的视觉任务，而非先前的示例、固定的镜头数量或自动的远景到特写序列。每个镜头需有明确的目的和视觉优先级。仅当下个镜头会沿用中间结果时才描述该中间结果；务必展示最终结果。后续剪辑时间点需精确、递增，且处于规定时长内，并采用模型标记法表示。
- 镜头切换时，除非用户要求不连贯，否则需保留位置、身份、朝向、延续的动作以及已改变的世界状态。仅当下个镜头能补充新信息时才会进行切换；细微变化可通过摄像机移动来实现。
- 保持游戏玩法逻辑的清晰性——即角色、目标或威胁、动作及结果。整个流程需控制在`duration_sec`范围内，且结果或反应需可见。
- 通过相应的视线、身体朝向、重心转移、面部表情、手部或道具使用以及语音表达来展现意图和努力程度。表演流程可按“准备→动作→必要时的互动/反应→恢复或维持的结果”来安排。同时进行的动作需符合人体解剖学逻辑，对话需有清晰的说话节奏。
- 正面表述空间和因果约束：说明角色和摄像机的位置、朝向或移动方向，以及发生的变化。切勿罗列一堆无关的否定性限制条件。

紧凑的镜头顺序：构图与主体→可见动作→摄像机动作→同步音效→最终呈现的状态。请勿提交仅包含情节概述的内容、信息过于密集的简短片段描述、无效的剪辑时间点说明、不断变化的参考角色设定、没有过渡路径的静态关键帧描述，以及提示词中包含的提供者或元数据文本。
