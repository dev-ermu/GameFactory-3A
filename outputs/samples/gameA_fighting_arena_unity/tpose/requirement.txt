# T-pose Image Generation Requirements — gameA_fighting_arena_unity

## Overview
Generate clean T-pose reference images for each fighting character. These
images serve as input to the 3D object generation pipeline. The T-pose image
generator (Seedream + 白底抠图) takes an original character image and a
text description, then produces a clean, front-facing T-pose image with the
background removed.

## Model Backend
- **Generation**: doubao-seedream-5-0-260128 (image editing model)
- **Matting / Background Removal**: 纯白背景抠图（无需模型）

## Input Requirements
- Source images: original character reference images (front-facing full body)
- Description: detailed text describing the character's appearance

## Output Requirements
- Clean T-pose image with transparent background (RGBA PNG)
- Front-facing, arms along X-axis (standard T-pose)
- Resolution: 1024×1024 (target_size)
- Diffusion steps: 40

## Output Path
- outputs/runs/gameA_fighting_arena_unity/<run_id>/assets/tpose/<task_id>/tpose_fg.png

## Notes
- The T-pose images are the primary input for 3D object generation
- Background must be fully removed (alpha channel) for clean 3D mesh extraction
- Characters should face forward with arms extended horizontally
- The generated T-pose images should be copied/placed into the 3D_object/ref_images/
  directory for the subsequent 3D object generation step
