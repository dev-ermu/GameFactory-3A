# gameB_forest_adventure_ue — General Requirement

## Game Overview
- **Game ID**: gameB_forest_adventure_ue
- **Genre**: Third-person exploration RPG (自由探索RPG)
- **Visual Reference**: Zelda Breath of the Wild (塞尔达传说) — calm exploration
- **Engine**: Unreal Engine 5
- **Player**: Single player

## Core Gameplay
- Third-person camera following the player character
- Explore a countryside map freely
- No combat — focus on discovery and interaction
- Press E to interact with NPCs and objects
- A generated stone tablet (石碑) near the start tells the player:
  "This area holds three treasure chests. Go explore and find them."
- Three treasure chests are scattered across the map
- Each treasure chest has a different NPC wandering nearby
- NPCs can be talked to (press E) — they hint that a treasure is nearby
- Bats fly around near each treasure chest location as ambient atmosphere
- Find and open all 3 chests to complete the game

## Characters

### Player — Explorer (探索者)
- Humanoid character, third-person view
- Can walk, run/sprint
- Can interact with NPCs and objects (press E)

### NPCs (3 different characters)
- Each NPC wanders near a treasure chest location
- Different appearance for each NPC
- When approached and E is pressed, they speak:
  - NPC 1: "I saw something glowing near the old tree. Could be a treasure chest."
  - NPC 2: "There's a strange chest by the river. I'd check it out if I were you."
  - NPC 3: "A treasure chest lies hidden near the ruins. Seek it out!"

### Bats (ambient creatures)
- Bats fly in circles near each treasure chest
- Non-hostile, purely atmospheric
- Generated 3D models with simple fly animation

## Objects

### Stone Tablet (石碑)
- Generated 3D model
- Placed near the player spawn point
- Text inscribed: "This area holds three treasure chests. Go explore and find them."
- Interactable (press E to read)

### Treasure Chests (宝箱)
- 3 chests scattered across the map at different locations
- Each chest can be opened (press E when nearby)
- Opening a chest shows a reward message
- Chest open animation plays
- Opening all 3 completes the game

## Motion Set
### Player Motions (4 actions)
1. idle - standing idle, breathing
2. walk - normal walking
3. run - sprint
4. interact - reaching out to interact (press E)

### NPC Motions (2 actions each)
1. idle - standing
2. wander - slow walking in a small area

### Bat Motions (1 action)
1. fly - flapping wings, circling flight

## Scene
- Countryside map (imported open-source racing baseline countryside)
- Open fields, trees, hills, paths
- Natural daylight, bright and calm atmosphere
- Three treasure chest locations spread across the map:
  1. Near an old tree
  2. By a river
  3. Near ruins
- Stone tablet placed at spawn area
- Bats circling each chest location

## Game Mechanics (UE5 Blueprint / C++)
- RPGPlayerController — third-person movement, sprint, interaction
- RPGInteractSystem — E key interaction with NPCs, stone tablet, chests
- RPGDialogueSystem — NPC dialogue display, text UI
- TreasureChest — chest open logic, reward, progress tracking
- RPGGameProgress — tracks chests opened, win condition (3/3)
- RPGCameraController — third-person follow camera
- BatFlock — bat spawning and circling flight behavior
- NPCWander — NPC idle and wander AI

## UI Design
- Interaction prompt: "Press E to interact" when near NPC/chest/tablet
- Dialogue box: text display when talking to NPC, bottom of screen
- Progress tracker: "Treasure Chests: 1/3" top-right
- Stone tablet text: full-screen overlay when reading
- Chest open message: "You found a treasure!" pop-up
- Game complete: "All treasures found! Press Enter to Restart"
- Pause menu: Esc to pause

## Controls

| Action | Key |
|--------|-----|
| Move | WASD |
| Sprint | Shift |
| Interact | E |
| Pause | Esc |

## MVP Playable Loop
Launch → Spawn → Read Stone Tablet → Explore → Find NPC → Dialogue →
Find Chest → Open → Progress → Next Chest → All 3 Found → Complete → Restart

## Acceptance Criteria
- UE5 launches without compilation errors
- Player character spawns in third-person view
- Camera follows player smoothly
- WASD moves player, Shift sprints
- Stone tablet is placed near spawn and can be read (press E)
- Stone tablet displays "three treasure chests" message
- 3 treasure chests are placed at different map locations
- Each chest has an NPC wandering nearby
- NPC can be talked to (press E) — dialogue text appears
- NPC dialogue hints about nearby treasure
- Bats are visible flying near each chest location
- Chest can be opened (press E when near)
- Chest open animation plays
- Progress tracker shows "X/3" chests opened
- Opening all 3 chests triggers game complete screen
- "Press Enter to Restart" works
- Interaction prompt appears when near interactable objects
