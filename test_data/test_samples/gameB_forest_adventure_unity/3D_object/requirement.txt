# 3D Object Generation Requirements — gameB_forest_adventure_unity

## 概述

本目录包含 gameB_forest_adventure_unity（自由探索 ARPG）所需的全部 3D 物体生成任务。
角色和怪物的 3D 模型通过 T-pose 参考图生成（T-pose image → 3D model），
道具通过参考图生成（ref image → 3D model）。

---

## 生成方式

| 资产类型 | 生成方式 | 模型 | 质量要求 |
|---------|---------|------|---------|
| 人物角色 | T-pose image → 3D model | Tripo / Meshy | ≤100k tris, PBR 2048 |
| 怪物 | T-pose image → 3D model | Tripo / Meshy | ≤30k tris, PBR 2048 |
| 道具 | ref image → 3D model | Tripo / Meshy | ≤10k tris, PBR 2048 |

## 输出路径

所有生成的 3D 物体输出到:
```
outputs/gameB_forest_adventure_unity/3D_object/<task_id>/
  ├── model.glb
  ├── model.obj
  ├── textures/
  │   ├── albedo.png
  │   ├── normal.png
  │   ├── metallic.png
  │   └── roughness.png
  └── preview.png
```

## 注意事项

1. 角色/怪物模型必须包含标准 Humanoid 骨骼绑定，以便后续 MoMask 动作 retarget
2. 宝箱模型需要支持开合动画（分为箱体和箱盖两部分）
3. 所有模型必须使用 PBR 纹理流程（Albedo, Normal, Metallic, Roughness）
4. UV 必须无重叠，纹理分辨率统一为 2048×2048
5. 模型朝向：面朝 +Z 方向，T-pose 手臂沿 X 轴水平展开
